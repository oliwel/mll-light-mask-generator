Hilfe: Basis erweitert

raum Abmessungen

Format Breite, Tiefe, Höhe
Offset x, y (Maske kleiner als Raum)
Offset-Varianten ein Wert für alle Seiten oder v,r,h,l
Fussbodenhöhe als letzter Wert (x,y,fb / v,r,h,l,fb); wird von jeder Fensterhöhe abgezogen
Stockwerk G<n> als eigene Zeile (G0 = Erdgeschoss)

licht Hausplatine

Format offset_x, offset_y, (schalter), (anschluss)
Ursprung: vorne links zur Mitte der Platine!
Ohne Werte zentriert
Schalter weiter, ende
Anschluss idc IDC Buchse, stack nur Führung
Weglassen Abschnitt weglassen = keine Platine
Mehrstöckige Häuser: Stockwerk G<n> im Abschnitt raum setzen, um die Platine zu drehen.

vorne hinten links rechts Fenster

Format Links, Unten, Breite, Höhe – eine Öffnung pro Zeile
Links/Unten = Abstand der Fensterecke zum Nullpunkt
Ursprung je Wand unten, links
Mit Fussbodenhöhe y_start ab Erdboden
Massiv Wand ohne Fenster: 0,0,0,0
Trennwand einzelne Zahl = Position (automatisch), zwei Zahlen = mit Länge
Keine Fenster = keine Wand!

text Beschriftung

Format Hausname (ohne Komma)

dach Dach

Öffnungen wie Fenster, Ursprung vorne, links
Alternativ plcc2, plcc6, ws2812, 3mm, 5mm, none

wand Innenwände

Format x_start, y_start, x_ecke1, y_ecke1, ...
Mehrere Paare = neue Wand entlang mehrerer Punkte
Ein Paar = verlängert die vorige Wand
Benannt x1,y1,name,x2,y2

druck Druckparameter

Format keyword, wert
innen Innenwände (Standard 1.0, min. 0.8) · aussen Außenwände (Standard 1.2, min. 0.8) · dach Dach (Standard und min. 1.2)

box Lichtbox

Format Breite, Höhe, Tiefe

oben links rechts LED-Flächen

Format Typ, (Clip), (Offset Breite), (Offset Tiefe) – eine LED pro Zeile
Ursprung Mitte der Fläche
Typen 3mm, 5mm, plcc6, plcc2, ws2812, none
Clip ohne, einfach, doppel (Standard: ohne)

Alle Angaben in Millimetern! Nachkommastellen sind mit Punkt als Trennzeichen möglich. Der Ursprung ist immer die Ecke unten/links der Fläche.

Assistent – Basiskonfiguration

Abmessungen des Hauses (Empfehlung: Außenmasse angeben und Maske durch Versatz anpassen).

Um diesen Betrag wird die gedruckte Maske kleiner als der Raum: erster Wert links/rechts, zweiter Wert vorne/hinten.

Das Stockwerk dreht die Lichtplatine und erstellt Zapfen und Nasen zum Stapeln.

Höhe des Fussbodens dieses Stockwerks über dem Erdboden; wird von jeder Fensterhöhe abgezogen.

Wände

Definiere für die vier Aussenwände das erste Fenster und die Position der (ersten) Trennwand, weitere Fenster und Wände kannst du nachher in der Textbox einfügen!
